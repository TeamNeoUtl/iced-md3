# iced-md3

[iced_m3](https://github.com/tpaau/iced_m3) のソフトフォークです。

[iced](https://iced.rs/) 向けに [Material Design 3](https://m3.material.io/) 準拠のコンポーネントを実装しています。

## 利用方法

`Cargo.toml` に以下を追加します。

```toml
iced_m3 = { git = "https://github.com/tapaau/iced_m3", branch = "main" } # 本家（tapaau/iced_m3）を用いる場合

iced-md3 = { git = "https://github.com/TeamNeoUtl/iced-md3", branch = "main" } # 本フォーク（TeamNeoUtl/iced-md3）を用いる場合
```
